## 🛠️ Tech Stack
- **Frontend Framework:** React 18
- **Styling:** Tailwind CSS (Cyber Dark aesthetic, Frosted Glassmorphism)
- **Animation:** Continuous LERP physics damping, 60fps canvas scrubbing, Framer Motion pop-up transitions
- **Build Tool:** Vite
- **Deployment:** Vercel

## 💻 Local Setup & Development
```bash
# Clone the repository
git clone https://github.com/Mouleeshwaranv/New_Portfolio-.git

# Navigate to frontend
cd "New_Portfolio-/frontend"

# Install dependencies
npm install

# Start development server
npm run dev
```
